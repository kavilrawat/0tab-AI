# 0tab AI

An open-source Chrome extension for bookmark shortcuts, smart tags, drag-and-drop organization, tab groups, and optional AI assistance from the omnibox.

## Install locally

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Choose **Load unpacked** and select this folder.

AI features that use OpenAI require the user to configure their own API key in the extension settings. The key is not included in this repository.
